## Graphify

For relevant code changes, query `graphify-out/graph.json` first with `graphify query "<focused question>"`; use `graphify path` or `graphify affected` for component relationships and impact. Confirm results in source before editing. Read `GRAPH_REPORT.md` only for broad reviews or when a focused query is insufficient. After structural or dependency changes, refresh with `graphify update .`. The project skill is available at `.claude/skills/graphify/SKILL.md` for `/graphify` requests. Graphify complements source review; code remains authoritative.
